## 📌 O projektu
Krátká 2D ragdoll fyzikální hra postavená v engine Godot. Hráč ovládá stickmana, švihá se na tyčích, dělá triky ve vzduchu a snaží se zachytávat na hrazdě, aby se rozplácl o zem.
